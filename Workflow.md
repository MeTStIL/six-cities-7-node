# Как работать над проектом

## Окружение

Для удобства работы над проектом используются инструменты из **Node.js** и **npm**. Все необходимые настройки произведены. Убедитесь, что на рабочем компьютере установлен актуальный LTS релиз Node.js**. Актуальная версия **Node.js** указана в файле `package.json` в поле `node`. Затем, в терминале, перейдите в директорию с проектом и _единожды_ запустите команду:

```bash
npm install
```

Команда запустит процесс установки зависимостей проекта из **npm**.

### Сценарии

В `package.json` предопределено несколько сценариев.

#### Запустить проект

```bash
npm start
```

Запускает основной модуль приложения (`src/main.ts`) с помощью `vite-node` без предварительной сборки. Удобно для этапа разработки.

#### Запустить CLI-приложение (Dev)

```bash
npm run dev-cli
```

Выполняет CLI-модуль (`src/main.cli.ts`) через `vite-node`. Предназначено для разработки и тестирования консольных команд.

#### Собрать проект

```bash
npm run build
```

Выполняет полноценную сборку: запускает проверку типов, удаляет старую директорию `dist`, собирает бандл с помощью **Vite** и выдает права на исполнение для CLI-файла (`chmod u+x`).

#### Проверить типы

```bash
npm run typecheck
```

Запускает компилятор TypeScript для проверки кодовой базы на ошибки типизации без генерации `.js` файлов.

#### Запустить мок-сервер

```bash
npm run mock:server
```

Запускает локальный тестовый сервер с помощью `json-server` на порту `3000`. В качестве базы данных используются данные из файла `./mocks/mock-server-data.json`.

#### Проверить линтером

```bash
npm run lint
```

Запуск проверки проекта статическим анализатором кода **ESLint**. Линтер проверяет файлы только внутри директории `src`.

#### Скомпилировать проект (tsc)

```bash
npm run compile
```

Создает директорию `dist` и компилирует проект стандартным компилятором `tsc` согласно конфигурации в `tsconfig.json`.

#### Удалить скомпилированный проект

```bash
npm run clean
```

Удаляет директорию `dist`.

## Структура проекта

### Директория `src`

Исходный код проекта: компоненты, модули и так далее. Структура директории `src` может быть произвольной.

### Файл `Readme.md`

Инструкции по работе с учебным репозиторием.

### Файл `Contributing.md`

Советы и инструкции по внесению изменений в учебный репозиторий.

### Остальное

Все остальные файлы в проекте являются служебными. Пожалуйста, не удаляйте и не изменяйте их самовольно. Только если того требует задание или наставник.
